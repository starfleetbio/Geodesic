# Full-face kit — now with debossed labels (16 panels + 2 arcs)

Every triangular panel now has ID marks **debossed 0.6 mm into the inner face** (the pocket
side — hidden on the finished dome, facing up while printing so it engraves cleanly, no supports):

- **Shape name** (T1 / T2 / T3L / T3R / T4 / T5) in the center, reading upright along the long edge.
- **Chord letter** (A–F) on the rim band beside each edge, so you can see at a glance which edge
  mates to which. Letters read correctly when you look at the inner face.

The outer (glossy show) face is untouched.

## Contents
- `singles/` — one flat, correctly-oriented STL of each shape (panels outer-face-down, arcs on their
  foot). Import, then **Clone** to the counts below, then press **A** to auto-arrange.
- `FACE_p1..p3.stl` — the whole face pre-packed on 3 plates, ready to slice.

## Counts for one full spherical triangle
3× T1, 3× T2, 3× T3L, 3× T3R, 3× T4, 1× T5, 1× arcT2T3, 1× arcT5T3  (16 panels + 2 arcs)

## Slicer
Brim ON, elephant's-foot ~0.15 mm, supports OFF. Don't auto-orient — parts are already correct.
The deboss is 0.6 mm (3 layers at 0.2 mm), so it stays crisp even with a brim.
